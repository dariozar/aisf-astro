# AGENTS.md — aisf-astro

Astro 5 SSG site for AISF (Associazione Italiana Studenti di Fisica).
Repo: `github.com/dariozar/aisf-astro` (branch `master`).
Live: `https://dariozar.github.io/aisf-astro/` (GitHub Pages, auto-deploy on push).
Design source of truth: `prototype/` HTML in the sibling WordPress Studio folder
(`../aisf-new-site/prototype/project/`) — plus `design-system.html` + `styles.css` tokens.

## Stack

- Astro 5 (SSG, `npm run build` → `dist/`), strict TS
- Tailwind CSS v4 via `@tailwindcss/vite` — tokens in `src/styles/global.css` (`@theme`)
- Starwind UI v3 vendored (`src/components/starwind/`, `starwind.config.json`):
  themed via `:root` var remap in `global.css`. Prefer themed Starwind
  (Badge/Button/Card/Sheet) over hand-rolled components.
- Content layer (`src/content.config.ts`): `events` + `news` via `glob()`,
  `committees` / `executive` / `executivePast` / `documents` via `file()` on
  `src/data/*.yml`. `file()` entries REQUIRE unique `id`.
- CMS: PagesCMS, config `.pages.yml` at root (must stay in sync with
  `content.config.ts` schemas — a field missing there gets dropped on save).
  Media: `public/images` ↔ `/images`.

## Commands

- `npm run dev -- --host 0.0.0.0 --port 4321` — dev server (machine also answers on Tailscale as `akkad`)
- `npm run build` — static build, always run before finishing
- `python3 scripts/migrate.py` — re-import old Jekyll site (`/tmp/opencode/ai-sf-github`
  clone of `ai-sf/ai-sf.github.io`); deterministic + idempotent. Paths rewritten
  `/img/` → `/images/`. Documents get `ord` sequence (do NOT reorder by hand —
  the `file()` loader does not preserve YAML order).
- Screenshots: `/tmp/opencode/cdp/shot.js <url> <scrollY> <name>` (Playwright,
  saves to `src/.shots/` — git-ignored). Use for every visual change:
  screenshot → change → screenshot.

## Architecture

- `src/layouts/BaseLayout.astro` — fonts (Google CDN), nav, footer, OG/meta
- `src/components/SiteNav.astro` — all nav logic lives here (single component).
  Transparent melt at top → light glass pill past 24px. The pill is STATIC
  (no dark/light switching — killed after repeated stuck-state bugs).
  Glass lives on inner `.nav-inner` div, NOT the `<nav>` root: `backdrop-filter`
  traps `position: fixed` descendants (broke the mobile Sheet drawer).
  Mobile drawer = Starwind Sheet with `targetId`, content padded to clear pill.
- `src/components/ItalyMap.astro` — GENERATED by `scripts/make_map.py`
  (least-squares fit of SVG lat/lon dots). Never hand-edit dots; rerun script.
- `src/components/EventDate.astro`, `EventType.astro` — humanize ISO dates /
  `eventonazionale` slugs. Always use them instead of raw fields.
- `[slug].astro` hides covers missing from `public/` (build-time `fs.existsSync`).

## Deploy (GitHub Pages)

- Push to `master` → `.github/workflows/deploy.yml` (official Astro action)
  builds and deploys. Pages source = GitHub Actions.
- `astro.config.mjs` pins `site` + `base: '/aisf-astro'`. ALL root-absolute
  links/assets MUST go through `u()` from `src/lib/url.ts` (uses
  `import.meta.env.BASE_URL`) — including nav arrays, `linkBase` props, and
  data-driven image paths (`cover`, `photo`). Unprefixed links 404 in prod.
- After link refactors, rebuild and grep `dist/` for unprefixed
  `(href|src)="/(eventi|comitati|…)"` before pushing.

## Gotchas (learned the hard way)

1. **Cascade layers**: Tailwind v4 utilities beat `@layer components` regardless of
   specificity. State overrides MUST be unlayered CSS or they silently lose.
2. **Hero overlay paint order**: hero gradient overlay covers static content in
   the `-mt-12` overlap band. Anything there needs positioning (`relative z-10`).
   Prototype lifts all of `.quicklinks` (`z-index: 5`) — mirror that.
3. **Fractional Tailwind classes**: `size-2.5` is never generated. Use `size-3` or
   arbitrary values (`size-[10px]`).
4. **Astro whitespace**: newline + `{expr}` collapses (e.g. `ateneo.{n}` with no
   space). Use explicit `{" "}`.
5. **Dev server staleness**: HMR sometimes misses CSS/data changes and the dev
   content cache needs a restart after data edits. When in doubt, restart and
   re-screenshot. Production builds always read fresh.
6. **`z-100`** works (v4 bare values). `text-paper/92`-style opacities are fine.
7. Every `file()` YAML entry needs unique `id`; CMS-added documents rows without
   `ord` sort last (schema default) — correct for new meetings, wrong for new
   years (set `ord` explicitly, documented in `.pages.yml`).
